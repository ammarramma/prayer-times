# Prayer Times TUI 🕌

Aplikasi waktu shalat berbasis Go yang mendukung kota di seluruh dunia melalui koordinat dan timezone IANA. Kemenag RI tetap menjadi metode default, dengan koreksi ihtiyati untuk mempertahankan konvensi waktu Indonesia.

## Status proyek

Core worldwide dan kalkulasi selesai. Aplikasi membuka TUI Bubble Tea untuk navigasi tanggal; opsi `-date` tetap menghasilkan satu jadwal non-interaktif. Lihat [langkah.md](./langkah.md) untuk status detail.

## Fitur kalkulasi

- Lokasi dengan nama, lintang, bujur, timezone IANA. Default: Lhokseumawe (5.1801, 97.1406, `Asia/Jakarta`).
- Metode kalkulasi: Kemenag RI (Fajr 20°, Isha 18°), MWL, Umm al-Qura, Egyptian, Karachi, ISNA, Singapore, Dubai, Moonsighting Committee, Kuwait, Qatar, dan UOIF.
- Madhab Asr: Shafii (default) atau Hanafi.
- Aturan lintang tinggi: Middle of the Night, Seventh of the Night, Twilight Angle.
- Ihtiyati khusus Kemenag: default +2 menit untuk Subuh, Dzuhur, Ashar, Maghrib, Isya, dan −2 menit untuk Terbit. Untuk metode lain tidak ada koreksi ihtiyati dari aplikasi.
- Imsak opsional dihitung 10 menit sebelum Subuh.
- Waktu yang memiliki detik dibulatkan ke atas ke menit berikutnya.

## Menjalankan

```bash
go run .
```

Di TUI gunakan panah kiri/kanan untuk memilih hari sebelumnya/berikutnya, `t` untuk kembali ke hari ini menurut timezone lokasi, dan `q` atau Ctrl+C untuk keluar. TUI berjalan inline secara default agar hasilnya tetap berada di scrollback. Gunakan `-fullscreen` untuk menjalankannya di alt screen dan menempatkan konten di tengah layar. Lokasi, metode, madhab, aturan lintang, ihtiyati, dan tanggal dapat diberikan lewat flag yang sama seperti contoh di bawah; seluruh opsi tetap memakai kalkulasi core yang sama.

Flag opsional:

```bash
go run . \
  -name London -lat 51.5072 -lon -0.1276 -tz Europe/London \
  -method mwl -madhab hanafi -high-latitude seventh_of_the_night \
  -date 2026-10-28
```

Daftar flag:

| Flag | Default | Keterangan |
| --- | --- | --- |
| `-config` | `~/.config/prayer-times/config.json` | Path config JSON; mengikuti direktori config OS |
| `-name` | `Lhokseumawe` | Nama kota/lokasi |
| `-lat` | `5.1801` | Lintang desimal, −90 sampai 90 |
| `-lon` | `97.1406` | Bujur desimal, −180 sampai 180 |
| `-tz` | `Asia/Jakarta` | Zona IANA (mis. `Europe/London`, `Asia/Riyadh`) |
| `-method` | `kemenag` | Salah satu metode di atas |
| `-madhab` | `shafii` | `shafii` atau `hanafi` |
| `-high-latitude` | `middle_of_the_night` | `middle_of_the_night`, `seventh_of_the_night`, `twilight_angle` |
| `-ihtiyati` | `2` | Menit koreksi khusus Kemenag; nilai metode lain diabaikan |
| `-imsak` | `false` | Tampilkan Imsak = Subuh −10 menit |
| `-fullscreen` | `false` | Jalankan TUI pada alt screen dan pusatkan konten |
| `-date` | Hari ini di zona lokasi | Tanggal Gregorian `YYYY-MM-DD`; menghasilkan output sekali jalan |
| `-set-config` | `false` | Simpan nilai config/flag ke config lalu keluar |

Buat atau perbarui konfigurasi melalui flags, misalnya:

```bash
go run . -set-config -name London -lat 51.5072 -lon -0.1276 -tz Europe/London -method mwl
```

Berkas config memakai JSON bertingkat, misalnya:

```json
{
  "location": { "name": "London", "latitude": 51.5072, "longitude": -0.1276, "timezone": "Europe/London" },
  "options": { "method": "mwl", "madhab": "shafii", "high_latitude_rule": "middle_of_the_night", "ihtiyati_minutes": 0, "include_imsak": false }
}
```

Flags yang ditentukan selalu mengesampingkan nilai file config; ketika file belum ada, default kembali ke Lhokseumawe.

Contoh metode lainnya: `umm_al_qura`, `egyptian`, `karachi`, `isna`, `singapore`, `dubai`, `moonsighting_committee`, `kuwait`, `qatar`, `uoif`.

## Pengembangan

# Agent Context - Prayer Times TUI

## Tentang Proyek
Aplikasi jadwal waktu shalat worldwide yang mendukung kota mana pun dengan koordinat dan timezone IANA. Kemenag RI tersedia sebagai salah satu metode kalkulasi dan menjadi metode default yang menjaga akurasi untuk Indonesia. Proyek ini direncanakan dirilis ke AUR (Arch User Repository).

## Tech Stack
- **Bahasa**: Go
- **TUI Framework**: Bubble Tea (arsitektur ELM: Model, Update, View)
- **Styling**: Lipgloss (Charmbracelet)
- **Config Management**: Viper (`~/.config/prayer-times/config.json`)
- **Target Platform**: Linux (khususnya Arch Linux via AUR)

## Lokasi dan Kalkulasi
- **Lokasi Default**: Lhokseumawe, Aceh (5.1801, 97.1406; `Asia/Jakarta`); nama, koordinat, dan timezone lain diberikan melalui config/flag.
- `internal/prayer.Location` memakai timezone IANA, bukan timezone mesin.
- **Metode**: Kemenag (Fajr 20°, Isha 18°, default), MWL, Umm al-Qura, Egyptian, Karachi, ISNA, Singapore, Dubai, Moonsighting Committee, Kuwait, Qatar, UOIF.
- **Ihtiyati Kemenag**: default +2 menit untuk Subuh, Dzuhur, Ashar, Maghrib, Isya; Terbit dikurangi 2 menit. Imsak opsional adalah Subuh −10 menit. Metode lain tidak mendapat koreksi ihtiyati aplikasi.
- Pembulatan waktu keluaran: detik/nanodetik lebih dari nol selalu dibulatkan naik ke menit berikutnya.
- Madhab Asr: Shafii (default) atau Hanafi. Aturan lintang tinggi: Middle of the Night (default), Seventh of the Night, atau Twilight Angle.
- Label presentasi berada di `internal/i18n` agar mendukung lokalisasi.

## Arsitektur
```
prayer-times/

```

## Prinsip Development
1. **Iteratif per Fase**: Setiap fase harus selesai sempurna dan di-commit sebelum lanjut ke fase berikutnya
2. **Akurasi First**: Logika waktu shalat harus 100% akurat sebelum UI disentuh
3. **Clean Commits**: Setiap fase memiliki commit tersendiri agar mudah di-recover
4. **Documentation**: Selalu update langkah.md setiap menyelesaikan sub-task

## Notes untuk Agent
- Gunakan bahasa Indonesia untuk dokumentasi dan commit messages
- Saat fase 1, jangan sentuh UI sama sekali - fokus pada akurasi kalkulasi
- Model lemah bisa refer ke file ini untuk context proyek
- Setiap fase harus verified working sebelum lanjut
- Core domain murni berada di `internal/prayer`; wiring entry point tetap tipis.
- Fixture akurasi Indonesia harus memakai jadwal Kemenag yang dapat direproduksi dan mencatat sumber/toleransi di `langkah.md`. Metode non-Kemenag tidak diberi ihtiyati aplikasi.

package main

import (
	"flag"
	"fmt"
	"os"
	"time"

	"github.com/ammarramma/prayer-times/internal/config"
	"github.com/ammarramma/prayer-times/internal/i18n"
	"github.com/ammarramma/prayer-times/internal/prayer"

	tea "github.com/charmbracelet/bubbletea"
)

func main() {
	configPathDefault, err := config.DefaultPath()
	if err != nil {
		fail("path konfigurasi", err)
	}
	configPath := flag.String("config", configPathDefault, "path file config JSON")
	name := flag.String("name", "", "nama kota/lokasi")
	latitude := flag.Float64("lat", 0, "lintang desimal")
	longitude := flag.Float64("lon", 0, "bujur desimal")
	timezone := flag.String("tz", "", "zona waktu IANA")
	method := flag.String("method", "", "metode (kemenag, mwl, umm_al_qura, egyptian, karachi, isna, singapore, dubai, moonsighting_committee, kuwait, qatar, uoif)")
	madhab := flag.String("madhab", "", "madhab Asr (shafii atau hanafi)")
	highLatitude := flag.String("high-latitude", "", "aturan lintang tinggi (middle_of_the_night, seventh_of_the_night, twilight_angle)")
	ihtiyati := flag.Int("ihtiyati", -1, "koreksi ihtiyati dalam menit (khusus Kemenag)")
	includeImsak := flag.Bool("imsak", false, "tampilkan imsak (10 menit sebelum Subuh)")
	fullscreen := flag.Bool("fullscreen", false, "jalankan TUI pada layar penuh (alt screen)")
	dateFlag := flag.String("date", "", "tanggal Gregorian YYYY-MM-DD (default hari ini di zona lokasi)")
	setConfig := flag.Bool("set-config", false, "simpan nilai flag lokasi/metode ke config, tanpa menjalankan TUI")
	flag.Parse()

	cfg, err := config.Load(*configPath)
	if err != nil {
		fail("config", err)
	}
	if *name != "" {
		cfg.Location.Name = *name
	}
	if flagWasSet("lat") {
		cfg.Location.Latitude = *latitude
	}
	if flagWasSet("lon") {
		cfg.Location.Longitude = *longitude
	}
	if *timezone != "" {
		cfg.Location.Timezone = *timezone
	}
	if *method != "" {
		cfg.Options.Method = prayer.Method(*method)
		if !flagWasSet("ihtiyati") {
			cfg.Options.IhtiyatiMinutes = prayer.DefaultOptions(cfg.Options.Method).IhtiyatiMinutes
		}
	}
	if *madhab != "" {
		cfg.Options.Madhab = prayer.Madhab(*madhab)
	}
	if *highLatitude != "" {
		cfg.Options.HighLatitudeRule = prayer.HighLatitudeRule(*highLatitude)
	}
	if *ihtiyati >= 0 {
		cfg.Options.IhtiyatiMinutes = *ihtiyati
	}
	if flagWasSet("imsak") {
		cfg.Options.IncludeImsak = *includeImsak
	}
	if *setConfig {
		if err := config.Save(*configPath, cfg); err != nil {
			fail("menyimpan config", err)
		}
		fmt.Printf("Konfigurasi tersimpan: %s\n", *configPath)
		return
	}
	location, err := time.LoadLocation(cfg.Location.Timezone)
	if err != nil {
		fail("zona waktu", err)
	}
	date := time.Now().In(location)
	if *dateFlag != "" {
		date, err = time.ParseInLocation("2006-01-02", *dateFlag, location)
		if err != nil {
			fail("tanggal", err)
		}
	}
	if *dateFlag != "" {
		times, err := prayer.Calculate(cfg.Location, date, cfg.Options)
		if err != nil {
			fail("kalkulasi", err)
		}
		printSchedule(cfg.Location, date, times)
		return
	}
	model := tui.New(cfg.Location, cfg.Options, date)
	model.Fullscreen = *fullscreen
	programOptions := []tea.ProgramOption{}
	if *fullscreen {
		programOptions = append(programOptions, tea.WithAltScreen())
	}
	program := tea.NewProgram(model, programOptions...)
	if _, err := program.Run(); err != nil {
		fail("TUI", err)
	}
}

func flagWasSet(name string) bool {
	set := false
	flag.Visit(func(current *flag.Flag) {
		if current.Name == name {
			set = true
		}
	})
	return set
}

func printSchedule(location prayer.Location, date time.Time, times prayer.PrayerTimes) {
	fmt.Println("===========================================")
	fmt.Printf("      %s\n", i18n.Title)
	fmt.Printf("      %s (%s)\n", location.Name, location.Timezone)
	fmt.Printf("      %s\n", i18n.FormatDate(date))
	fmt.Println("===========================================")
	if !times.Imsak.IsZero() {
		fmt.Printf("%-8s: %s\n", i18n.Imsak, times.Imsak.Format("15:04"))
	}
	fmt.Printf("%-8s: %s\n", i18n.Fajr, times.Fajr.Format("15:04"))
	fmt.Printf("%-8s: %s\n", i18n.Sunrise, times.Sunrise.Format("15:04"))
	fmt.Printf("%-8s: %s\n", i18n.Dhuhr, times.Dhuhr.Format("15:04"))
	fmt.Printf("%-8s: %s\n", i18n.Asr, times.Asr.Format("15:04"))
	fmt.Printf("%-8s: %s\n", i18n.Maghrib, times.Maghrib.Format("15:04"))
	fmt.Printf("%-8s: %s\n", i18n.Isha, times.Isha.Format("15:04"))
	fmt.Println("===========================================")
	fmt.Printf("%s: %s\n", i18n.Method, i18n.MethodName(string(times.Method)))
	fmt.Printf("%s: %s\n", i18n.Madhab, i18n.MadhabName(string(times.Madhab)))
	status := i18n.Disabled
	if times.Ihtiyati {
		status = fmt.Sprintf("%s (%d %s)", i18n.Enabled, times.IhtiyatiMinutes, i18n.MinutesSuffix)
	}
	fmt.Printf("%s: %s\n", i18n.Ihtiyati, status)
	fmt.Println("===========================================")
}

package config

import (
	"fmt"
	"os"
	"path/filepath"

	"github.com/ammarramma/prayer-times/internal/prayer"
	"github.com/spf13/viper"
)

// Config menyimpan lokasi serta opsi kalkulasi aplikasi.
type Config struct {
	Location prayer.Location `json:"location" mapstructure:"location"`
	Options  prayer.Options  `json:"options" mapstructure:"options"`
}

// Default mengembalikan konfigurasi awal Kemenag di Lhokseumawe.
func Default() Config {
	return Config{
		Location: prayer.DefaultLocation(),
		Options:  prayer.DefaultOptions(prayer.MethodKemenag),
	}
}

// DefaultPath mengembalikan lokasi file config standar XDG.
func DefaultPath() (string, error) {
	base, err := os.UserConfigDir()
	if err != nil {
		return "", fmt.Errorf("mencari direktori konfigurasi user: %w", err)
	}
	return filepath.Join(base, "prayer-times", "config.json"), nil
}

// Load membaca file JSON Viper bila tersedia; opsi flag dapat menimpa hasilnya.
func Load(path string) (Config, error) {
	cfg := Default()
	v := viper.New()
	v.SetConfigFile(path)
	v.SetConfigType("json")
	if err := v.ReadInConfig(); err != nil {
		if _, statErr := os.Stat(path); os.IsNotExist(statErr) {
			return cfg, nil
		}
		return Config{}, fmt.Errorf("membaca config %s: %w", path, err)
	}
	if err := v.Unmarshal(&cfg); err != nil {
		return Config{}, fmt.Errorf("mem-parsing config %s: %w", path, err)
	}
	mergeDefaults(&cfg)
	return cfg, nil
}

// Save menulis konfigurasi JSON ke path dan membuat direktori bila diperlukan.
func Save(path string, cfg Config) error {
	if err := os.MkdirAll(filepath.Dir(path), 0o700); err != nil {
		return fmt.Errorf("membuat direktori config: %w", err)
	}
	v := viper.New()
	v.SetConfigFile(path)
	v.SetConfigType("json")
	v.Set("location", cfg.Location)
	v.Set("options", cfg.Options)
	if err := v.WriteConfigAs(path); err != nil {
		return fmt.Errorf("menulis config %s: %w", path, err)
	}
	return os.Chmod(path, 0o600)
}

func mergeDefaults(cfg *Config) {
	defaults := Default()
	if cfg.Location.Name == "" {
		cfg.Location.Name = defaults.Location.Name
	}
	if cfg.Location.Timezone == "" {
		cfg.Location.Timezone = defaults.Location.Timezone
	}
	if cfg.Location.Latitude == 0 && cfg.Location.Longitude == 0 {
		cfg.Location.Latitude, cfg.Location.Longitude = defaults.Location.Latitude, defaults.Location.Longitude
	}
	if cfg.Options.Method == "" {
		cfg.Options.Method = defaults.Options.Method
	}
	if cfg.Options.Madhab == "" {
		cfg.Options.Madhab = defaults.Options.Madhab
	}
	if cfg.Options.HighLatitudeRule == "" {
		cfg.Options.HighLatitudeRule = defaults.Options.HighLatitudeRule
	}
}

package config

import (
	"os"
	"path/filepath"

func TestLoadMissingConfigUsesDefaults(t *testing.T) {
	cfg, err := Load(filepath.Join(t.TempDir(), "missing.json"))
	if err != nil {
		t.Fatal(err)
	}
	if cfg != Default() {
		t.Fatalf("Load missing = %#v, mau %#v", cfg, Default())
	}
}

func TestSaveAndLoadRoundTrip(t *testing.T) {
	path := filepath.Join(t.TempDir(), "nested", "config.json")
	want := Config{
		Location: prayer.Location{Name: "London", Latitude: 51.5072, Longitude: -0.1276, Timezone: "Europe/London"},
		Options:  prayer.Options{Method: prayer.MethodMWL, Madhab: prayer.MadhabHanafi, HighLatitudeRule: prayer.SeventhOfTheNight, IhtiyatiMinutes: 0, IncludeImsak: true},
	}
	if err := Save(path, want); err != nil {
		t.Fatal(err)
	}
	got, err := Load(path)
	if err != nil {
		t.Fatal(err)
	}
	if got != want {
		t.Fatalf("round trip = %#v, mau %#v", got, want)
	}
	info, err := os.Stat(path)
	if err != nil {
		t.Fatal(err)
	}
	if info.Mode().Perm() != 0o600 {
		t.Errorf("permission config = %o, mau 600", info.Mode().Perm())
	}
}

	path, err := DefaultPath()
	if err != nil {
		t.Fatal(err)
	}
	if filepath.Base(path) != "config.json" || filepath.Base(filepath.Dir(path)) != "prayer-times" {

// Method is a supported adhango calculation preset or the Kemenag preset.

const (

	MethodISNA                  Method = "isna"
	MethodSingapore             Method = "singapore"

// Calculate computes prayer times for the given Gregorian local date.
func Calculate(location Location, date time.Time, options Options) (PrayerTimes, error) {
	if location.Name == "" {
		return PrayerTimes{}, fmt.Errorf("nama lokasi tidak boleh kosong")
	}
	if math.IsNaN(location.Latitude) || math.IsInf(location.Latitude, 0) || location.Latitude < -90 || location.Latitude > 90 {
		return PrayerTimes{}, fmt.Errorf("lintang harus berada antara -90 dan 90")
	}
	if math.IsNaN(location.Longitude) || math.IsInf(location.Longitude, 0) || location.Longitude < -180 || location.Longitude > 180 {
		return PrayerTimes{}, fmt.Errorf("bujur harus berada antara -180 dan 180")
	}
	tz, err := time.LoadLocation(location.Timezone)
	if err != nil {
		return PrayerTimes{}, fmt.Errorf("timezone %q tidak valid: %w", location.Timezone, err)
	}
	if options.Method == "" {
		options.Method = MethodKemenag
		options.IhtiyatiMinutes = 2
	}
	if options.Madhab == "" {
		options.Madhab = MadhabShafii
	}
	if options.HighLatitudeRule == "" {
		options.HighLatitudeRule = MiddleOfTheNight
	}
	if options.IhtiyatiMinutes < 0 || options.IhtiyatiMinutes > 60 {
		return PrayerTimes{}, fmt.Errorf("ihtiyati harus antara 0 dan 60 menit")
	}
	method, params, err := parametersFor(options)
	if err != nil {
		return PrayerTimes{}, err
	}
	coords, err := util.NewCoordinates(location.Latitude, location.Longitude)
	if err != nil {
		return PrayerTimes{}, err
	}
	localDate := date.In(tz)
	components := data.NewDateComponents(localDate)
	solar := util.NewSolarTime(components, coords)
	transit, err := componentsAt(solar.Transit, components)
	if err != nil {
		return PrayerTimes{}, err
	}
	sunrise, err := componentsAt(solar.Sunrise, components)
	if err != nil {
		return PrayerTimes{}, err
	}
	sunset, err := componentsAt(solar.Sunset, components)
	if err != nil {
		return PrayerTimes{}, err
	}
	tomorrowComponents := data.NewDateComponents(localDate.AddDate(0, 0, 1))
	tomorrowSunrise, err := componentsAt(util.NewSolarTime(tomorrowComponents, coords).Sunrise, tomorrowComponents)
	if err != nil {
		return PrayerTimes{}, err
	}
	night := tomorrowSunrise.Sub(sunset)
	nightPortions, err := params.NightPortions()
	if err != nil {
		return PrayerTimes{}, err
	}
	dayOfYear := time.Date(components.Year, time.Month(components.Month), components.Day, 0, 0, 0, 0, time.UTC).YearDay()

	fajr, fajrErr := componentsAt(solar.HourAngle(-params.FajrAngle, false), components)
	if method == calc.MOON_SIGHTING_COMMITTEE && location.Latitude >= 55 {
		fajr = calc.SeasonAdjustedMorningTwilight(location.Latitude, dayOfYear, components.Year, sunrise)
		fajrErr = nil
	}
	safeFajr := sunrise.Add(-time.Duration(float64(night) * nightPortions.Fajr))
	if fajrErr != nil || fajr.Before(safeFajr) {
		fajr = safeFajr
	}

	isha := time.Time{}
	if params.IshaInterval > 0 {
		isha = sunset.Add(time.Duration(params.IshaInterval) * time.Minute)
	} else {
		isha, err = componentsAt(solar.HourAngle(-params.IshaAngle, true), components)
		if method == calc.MOON_SIGHTING_COMMITTEE && location.Latitude >= 55 {
			isha = sunset.Add(time.Duration(float64(night) / 7))
			err = nil
		}
		safeIsha := sunset.Add(time.Duration(float64(night) * nightPortions.Isha))
		if err != nil || isha.After(safeIsha) {
			isha = safeIsha
		}
	}
	asr, err := componentsAt(solar.Afternoon(calc.MadhabToShadowLengthMap[params.Madhab]), components)
	if err != nil {
		return PrayerTimes{}, fmt.Errorf("gagal menghitung Ashar: %w", err)
	}

	correction := 0
	if options.Method == MethodKemenag {
		correction = options.IhtiyatiMinutes
	}
	adjusted := func(t time.Time, methodMinutes int, ihtiyatiMinutes int) time.Time {
		return ceilToMinute(t.In(tz)).Add(time.Duration(methodMinutes+ihtiyatiMinutes) * time.Minute)
	}
	adjustments := params.MethodAdjustments
	result := PrayerTimes{
		Fajr:            adjusted(fajr, adjustments.FajrAdj, correction),
		Sunrise:         adjusted(sunrise, adjustments.SunriseAdj, -correction),
		Dhuhr:           adjusted(transit, adjustments.DhuhrAdj, correction),
		Asr:             adjusted(asr, adjustments.AsrAdj, correction),
		Maghrib:         adjusted(sunset, adjustments.MaghribAdj, correction),
		Isha:            adjusted(isha, adjustments.IshaAdj, correction),
		Method:          options.Method,
		Madhab:          options.Madhab,
		Ihtiyati:        options.Method == MethodKemenag && correction != 0,
		IhtiyatiMinutes: correction,
	}
	if options.IncludeImsak {
		result.Imsak = result.Fajr.Add(-10 * time.Minute)
	}
	return result, nil
}

func componentsAt(decimalHours float64, date *data.DateComponents) (time.Time, error) {
	components, err := data.NewTimeComponents(decimalHours)
	if err != nil {
		return time.Time{}, err
	}
	return components.DateComponents(date), nil
}

func ceilToMinute(t time.Time) time.Time {
	minute := t.Truncate(time.Minute)
	if t.Equal(minute) {
		return minute
	}
	return minute.Add(time.Minute)
}

func parametersFor(options Options) (calc.CalculationMethod, *calc.CalculationParameters, error) {
	methodMap := map[Method]calc.CalculationMethod{
		MethodKemenag:               calc.OTHER,
		MethodMWL:                   calc.MUSLIM_WORLD_LEAGUE,
		MethodUmmAlQura:             calc.UMM_AL_QURA,
		MethodEgyptian:              calc.EGYPTIAN,
		MethodKarachi:               calc.KARACHI,
		MethodISNA:                  calc.NORTH_AMERICA,
		MethodSingapore:             calc.SINGAPORE,
		MethodDubai:                 calc.DUBAI,
		MethodMoonsightingCommittee: calc.MOON_SIGHTING_COMMITTEE,
		MethodKuwait:                calc.KUWAIT,
		MethodQatar:                 calc.QATAR,
		MethodUOIF:                  calc.UOIF,
	}
	method, ok := methodMap[options.Method]
	if !ok {
		return 0, nil, fmt.Errorf("metode kalkulasi tidak dikenal: %q", options.Method)
	}
	params := calc.GetMethodParameters(method)
	if options.Method == MethodKemenag {
		params.FajrAngle = 20
		params.IshaAngle = 18
	}
	switch options.Madhab {
	case MadhabShafii:
		params.Madhab = calc.SHAFI_HANBALI_MALIKI
	case MadhabHanafi:
		params.Madhab = calc.HANAFI
	default:
		return 0, nil, fmt.Errorf("madhab tidak dikenal: %q", options.Madhab)
	}
	switch options.HighLatitudeRule {
	case MiddleOfTheNight:
		params.HighLatitudeRule = calc.MIDDLE_OF_THE_NIGHT
	case SeventhOfTheNight:
		params.HighLatitudeRule = calc.SEVENTH_OF_THE_NIGHT
	case TwilightAngle:
		params.HighLatitudeRule = calc.TWILIGHT_ANGLE
	default:
		return 0, nil, fmt.Errorf("aturan lintang tinggi tidak dikenal: %q", options.HighLatitudeRule)
	}
	return method, params, nil
}

package tui

import (

type tickMsg time.Time

// Model menyimpan konfigurasi jadwal serta tanggal yang sedang ditampilkan.
type Model struct {
	Location   prayer.Location
	Options    prayer.Options
	Date       time.Time
	Width      int
	Height     int
	Fullscreen bool
	now        time.Time
	times      prayer.PrayerTimes
	err        error
	quit       bool
	styles     styles
}

func New(location prayer.Location, options prayer.Options, date time.Time) Model {
	tz, err := time.LoadLocation(location.Timezone)
	if err == nil {
		date = date.In(tz)
	}
	m := Model{Location: location, Options: options, Date: date, now: time.Now(), Width: 100, styles: defaultStyles()}
	m.recalculate()
	return m
}

func (m Model) Init() tea.Cmd { return tick() }

func (m Model) Update(message tea.Msg) (tea.Model, tea.Cmd) {
	switch msg := message.(type) {
	case tea.WindowSizeMsg:
		m.Width = msg.Width
		m.Height = msg.Height
		return m, nil
	case tickMsg:
		m.now = time.Time(msg)
		return m, tick()
	case tea.KeyMsg:
		switch msg.String() {
		case "q", "ctrl+c":
			m.quit = true
			return m, tea.Quit
		case "left":
			m.Date = m.Date.AddDate(0, 0, -1)
			m.recalculate()
		case "right":
			m.Date = m.Date.AddDate(0, 0, 1)
			m.recalculate()
		case "t":
			if location, err := time.LoadLocation(m.Location.Timezone); err == nil {
				today := m.now.In(location)
				m.Date = time.Date(today.Year(), today.Month(), today.Day(), 0, 0, 0, 0, location)
				m.recalculate()
			}
		}
	}
	return m, nil
}

func (m Model) View() string {
	if m.quit {
		return ""
	}
	if m.err != nil {
		return m.styles.error.Render(fmt.Sprintf("Kesalahan kalkulasi: %v", m.err))
	}
	var view strings.Builder
	fmt.Fprintln(&view, m.styles.title.Render(i18n.Title))
	fmt.Fprintf(&view, "%s  ·  %s\n", m.Location.Name, m.Location.Timezone)
	fmt.Fprintln(&view, m.styles.date.Render(i18n.FormatDate(m.Date)))
	fmt.Fprintln(&view)

	isToday := displayedDateIsToday(m.Date, m.now, m.Location.Timezone)
	var upcoming prayerTime
	if isToday {
		var err error
		upcoming, err = nextPrayer(m.times, m.Date, m.now, m.Location, m.Options)
		if err != nil {
			return m.styles.error.Render(fmt.Sprintf("Kesalahan kalkulasi: %v", err))
		}
	}
	prayers := []struct {
		name string
		time time.Time
	}{
		{i18n.Fajr, m.times.Fajr},
		{i18n.Dhuhr, m.times.Dhuhr},
		{i18n.Asr, m.times.Asr},
		{i18n.Maghrib, m.times.Maghrib},
		{i18n.Isha, m.times.Isha},
	}
	boxes := make([]string, 0, len(prayers))
	for _, current := range prayers {
		content := fmt.Sprintf("%s\n%s", current.name, current.time.Format("15:04"))
		if isToday && current.name == upcoming.name && current.time.Equal(upcoming.time) {
			boxes = append(boxes, m.styles.next.Render(content))
		} else {
			boxes = append(boxes, m.styles.prayer.Render(content))
		}
	}
	if m.Width >= 90 {
		fmt.Fprintln(&view, lipgloss.JoinHorizontal(lipgloss.Top, boxes...))
	} else {
		fmt.Fprintln(&view, lipgloss.JoinVertical(lipgloss.Left, boxes...))
	}
	if isToday {
		fmt.Fprintf(&view, "BERIKUTNYA: %s\n", upcoming.name)
	}
	fmt.Fprintf(&view, "%s  %s\n", i18n.Sunrise, m.times.Sunrise.Format("15:04"))
	if !m.times.Imsak.IsZero() {
		fmt.Fprintf(&view, "%s  %s\n", i18n.Imsak, m.times.Imsak.Format("15:04"))
	}
	fmt.Fprintln(&view)
	metadata := fmt.Sprintf("%s: %s  ·  %s: %s  ·  %s: %s", i18n.Method, i18n.MethodName(string(m.times.Method)), i18n.Madhab, i18n.MadhabName(string(m.times.Madhab)), i18n.Ihtiyati, ihtiyatiLabel(m.times))
	metadataWidth := m.Width
	if metadataWidth < 1 {
		metadataWidth = 1
	}
	fmt.Fprintln(&view, lipgloss.NewStyle().MaxWidth(metadataWidth).Render(metadata))
	if isToday {
		fmt.Fprintf(&view, "Menuju %s: %s\n", upcoming.name, countdown(m.now, upcoming.time))
	}
	fmt.Fprintln(&view, m.styles.footer.MaxWidth(metadataWidth).Render("←/→: ubah hari   t: hari ini   q/Ctrl+C: keluar"))
	content := view.String()
	if m.Fullscreen {
		return lipgloss.Place(m.Width, m.Height, lipgloss.Center, lipgloss.Center, content)
	}
	return content
}

func (m *Model) recalculate() {
	m.times, m.err = prayer.Calculate(m.Location, m.Date, m.Options)
}

func (m Model) Times() prayer.PrayerTimes { return m.times }
func (m Model) Error() error              { return m.err }

func tick() tea.Cmd {
	return tea.Tick(time.Second, func(now time.Time) tea.Msg { return tickMsg(now) })
}

func nextPrayer(times prayer.PrayerTimes, date, now time.Time, location prayer.Location, options prayer.Options) (prayerTime, error) {
	entries := []prayerTime{
		{i18n.Fajr, times.Fajr}, {i18n.Dhuhr, times.Dhuhr}, {i18n.Asr, times.Asr}, {i18n.Maghrib, times.Maghrib}, {i18n.Isha, times.Isha},
	}
	zone, err := time.LoadLocation(location.Timezone)
	if err != nil {
		return prayerTime{}, err
	}
	currentDate := now.In(zone)
	for _, entry := range entries {
		if entry.time.After(currentDate) {
			return entry, nil
		}
	}
	tomorrow := date.In(zone).AddDate(0, 0, 1)
	tomorrow = time.Date(tomorrow.Year(), tomorrow.Month(), tomorrow.Day(), 0, 0, 0, 0, zone)
	tomorrowTimes, err := prayer.Calculate(location, tomorrow, options)
	if err != nil {
		return prayerTime{}, err
	}
	return prayerTime{i18n.Fajr, tomorrowTimes.Fajr}, nil
}

func displayedDateIsToday(date, now time.Time, timezone string) bool {
	location, err := time.LoadLocation(timezone)
	if err != nil {
		return false
	}
	return date.In(location).Format("2006-01-02") == now.In(location).Format("2006-01-02")
}

type prayerTime struct {
	name string
	time time.Time
}

func countdown(now, target time.Time) string {
	remaining := target.Sub(now)
	hours := int(remaining / time.Hour)
	minutes := int(remaining % time.Hour / time.Minute)
	seconds := int(remaining % time.Minute / time.Second)
	return fmt.Sprintf("%02d:%02d:%02d", hours, minutes, seconds)
}

func ihtiyatiLabel(times prayer.PrayerTimes) string {
	if !times.Ihtiyati {
		return i18n.Disabled
	}
	return fmt.Sprintf("%s (%d %s)", i18n.Enabled, times.IhtiyatiMinutes, i18n.MinutesSuffix)
}
