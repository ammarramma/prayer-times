# Prayer Times TUI 🕌

Aplikasi TUI (Text User Interface) untuk menampilkan jadwal waktu shalat yang akurat sesuai standar Kemenag Indonesia.

## Status: 🚧 Work in Progress

Proyek ini sedang dalam tahap development. Lihat [langkah.md](./langkah.md) untuk tracking progress.

## Roadmap

1. **Fase 1**: Core Logic - Kalkulasi waktu shalat akurat
2. **Fase 2**: Interaktivitas - Navigasi hari dengan Bubble Tea
3. **Fase 3**: Styling - Beautiful UI dengan Lipgloss
4. **Fase 4**: Konfigurasi - User-defined location & settings
5. **Fase 5**: AUR Release - Publish ke Arch User Repository

## Tech Stack

- **Go** - Bahasa pemrograman
- **Bubble Tea** - TUI framework (arsitektur ELM)
- **Lipgloss** - Styling untuk terminal
- **Viper** - Configuration management
